# FreshWeek — сайт доставки готовых рационов

Статический сайт на HTML, CSS и JS без сборки и зависимостей.

## Запуск
Откройте `index.html` в браузере. Или запустите локальный сервер:

    python3 -m http.server 8000

и перейдите на http://localhost:8000

## Структура
- `index.html` — главная (цели, популярные рационы, калькулятор калорий, отзывы, доставка и оплата, контакты)
- `menu.html` — меню с фильтрами по цели, калорийности, сроку и сортировкой
- `product.html?id=balance` — карточка рациона (состав по дням, аллергены, срок, дата, цена)
- `css/style.css` — все стили, адаптив для телефона и планшета
- `js/data.js` — рационы и блюда (здесь меняются названия, цены, состав)
- `js/app.js` — корзина, оформление заказа, фильтры, калькулятор, карточка
- `img/` — SVG-иллюстрации блюд (замените на фотографии: `img/dishes/<id>.svg` → `.jpg`, поправьте пути в `data.js`/`app.js`)

## Что нужно заменить перед запуском
- Название, телефон, почту, часы работы, условия доставки, цены, составы рационов.
- Отзывы — сейчас примеры.
- Утверждение «КБЖУ рассчитано диетологом» — оставьте, только если это правда.
- Заказы и заявки сохраняются в `localStorage` браузера (демо). Для реальной работы подключите серверную часть и оплату в `bindCheckout()` и `initContactForm()` в `js/app.js`.
